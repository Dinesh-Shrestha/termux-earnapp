Your Termux setup, made easier.

A guided setup script for EarnApp and useful Termux tools. Choose what you need from the menu and keep control of each step.

Get started Read the source

Made for Android and Termux

Runs as the regular Termux app user. No root access or sudo required.

ARMv7 ARM64 x86_64

Quick start

Install the setup script

Copy the command, paste it into Termux, and choose the setup you want.

TERMUX 
curl -fsSL https://termux-earnapp.dinesh29.com.np/earnapp-setup.sh -o earnapp-setup.sh && bash earnapp-setup.sh

The script downloads to your current Termux directory so you can inspect it before running it.

Choose what to set up

One menu, separate tasks

Each item can be run by itself. Choose Everything only when you want all listed tools.

1

Base update

Refresh package lists and upgrade Termux packages when requested.

2

Termux:Boot

Install termux-services and configure startup after reboot.

3

OpenSSH

Install and supervise the SSH server.

4

Cloudflared

Install Cloudflared and prepare service prerequisites.

5

udocker

Install udocker and verify it is available.

6

EarnApp

Bring up the EarnApp container as a supervised service.

7

speedtest-go

Install the CLI for on-demand internet speed tests.

8

Everything

Run all listed setup options in order.

After setup

Check the EarnApp service log

Follow startup and service output directly from Termux.

tail -f "$PREFIX/var/log/sv/earnapp/current"
