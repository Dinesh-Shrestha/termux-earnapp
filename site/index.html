A community guide to running EarnApp on Android with Termux and udocker. Follow the setup menu, register your device, and check the service logs.

Quick start

Install the setup script

Copy the command, paste it into Termux, and choose the setup you want.

TERMUX 
curl -fsSL https://termux-earnapp.dinesh29.com.np/earnapp-setup.sh -o earnapp-setup.sh && bash earnapp-setup.sh

The script downloads to your current Termux directory so you can inspect it before running it.

Setup guide

Install EarnApp on Termux in four steps

The guided script prepares the Termux service environment and runs EarnApp in a udocker container.

  1. 1

    Run the installer

    Paste the command above into Termux. It downloads the script and opens its interactive menu.

  2. 2

    Select menu option 6

    Choose EarnApp full bring-up. The script prepares service startup, verifies udocker, and creates the EarnApp container.

  3. 3

    Register your device

    Open the registration link printed by the script to associate the device with your EarnApp account.

  4. 4

    Check service status and logs

    Run sv status earnapp to check the service. Use the log command below to view its output.

After setup

Check the EarnApp service log

Follow startup and service output directly from Termux.

tail -f "$PREFIX/var/log/sv/earnapp/current"
