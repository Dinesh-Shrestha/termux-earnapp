EarnApp setup for Termux

Install and supervise EarnApp on Android with Termux and udocker.

Download the script and run it from Termux. It does not require root or sudo.

curl -fsSL https://termux-earnapp.dinesh29.com.np/earnapp-setup.sh -o earnapp-setup.sh
bash earnapp-setup.sh
Download installer View source on GitHub

EarnApp service logs: tail -f "$PREFIX/var/log/sv/earnapp/current"
